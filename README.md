# CSSCI 期刊人工智能使用政策数据集

> 中国人文社会科学核心期刊（CSSCI）人工智能（AI）使用政策的逐刊检索证据、
> 判定结果与检索过程记录。
>
> **版本 v1.0（2026-09-29 冻结）** — 本版本为论文引用版本，内容不再变更。

---

## 一、研究背景与数据范围

本数据集记录了对 **2025—2026 年度 CSSCI 来源期刊（674 种，26 个学科）**
逐一检索其人工智能使用政策的完整过程与结果，检索对象包括：

1. 对**投稿作者**使用 AI 工具的规定与要求；
2. 期刊**编审流程**中使用 AI 的政策；
3. 对**审稿人**使用 AI 的要求。

期刊名录以官方《CSSCI（2025—2026）来源期刊目录》为准（674 种）。
学科名与学科顺序均采用官方口径。

> **说明**：本项目早期以 662 种期刊、27 个学科（项目自设顺序）为工作基准，
> 后依官方目录调整为 674 种、26 个学科，序号体系整体重排。
> 新旧序号的换算见 `_校验-序号变更映射表.txt`。

### A / B / C 分类的含义

三类**不可混同**，尤其请勿将 B 类、C 类读作「无政策」：

| 类别 | 含义 |
|---|---|
| **A** | 已读取官方投稿须知/公告全文，**确认其中无 AI 条款** |
| **B** | 因知网验证码墙、微信验证墙、登录墙等受阻，官方文本**未能读取**——属「**未能核实**」，不是「确认无政策」 |
| **C** | **未找到可采信的官方渠道文本**（第三方中介站点一律不采信） |

## 四、数据结构

### 主表 `CSSCI期刊名单-674-2025-2026.xlsx`

单工作表 `Sheet1`，675 行（1 行表头 + 674 行数据）× 7 列：

| 列 | 字段 | 说明 |
|---|---|---|
| A | 序号 | 1–674，与官方学科顺序一致，与所有文档中的序号对应 |
| B | 学科 | 26 个官方学科名 |
| C | 期刊名称 | |
| D | AI政策链接 | **仅「找到政策」的 122 行有值**；A/B/C 类留空（不写「无」「-」） |
| E | 置信度 | 高 / 中 |
| F | 主办单位 | |
| G | 主管单位 | |

同一期刊有多个版本政策时，D 列填**最新版**链接，旧版仅存于学科证据目录。

### 证据文件命名

```
NN-学科名/序号-刊名-YYYYMMDD.txt              政策发布日期
NN-学科名/序号-刊名-作者政策-YYYYMMDD.txt      按政策类型区分
NN-学科名/序号-刊名-审稿人政策-YYYYMMDD.txt
```

日期不详时以版本号或「日期不详」标注。文件内容含：期刊信息、检索过程
（访问 URL、搜索词、技术障碍、排除的第三方站点）、来源链接、发布时间、
政策类型、**政策全文**、置信度。

### 检索报告结构

每份学科报告含：检索统计、找到政策的期刊详情、**未找到政策期刊的逐刊说明**
（主办单位、搜索词、访问 URL 及每项结果、排除站点、一句话结论）、
技术障碍与绕过路径、学科特点分析、下一步。

未找到政策的期刊**逐刊保留检索痕迹**，不以汇总清单代替。

## 五、LLM 使用情况说明

本数据集的检索与整理由 AI 编码助手（Claude）在人机协作下完成。
相关记录由本仓库内两份文档完整承载：

| 文档 | 作用 |
|---|---|
| `skill/SKILL.md` | **规则本体**：LLM 每一步该做什么、什么算有效证据、何时必须停下等待人工确认 |
| `检索工作日志.txt` | **执行记录**：逐次作业的时间戳日志，含全部检索动作、更正与口径变更 |

### 人机分工

- **LLM 承担**：网络检索与关键词组合、网页/Pdf 内容读取、候选结果筛选、
  证据文本转录、A/B/C 归类判定、报告撰写、台账与主表回填。
- **人工承担**：判定规则的事前设定与事中修订、受限来源（验证码墙等）的人工核查、
  机构政策适用范围的最终认定、每一步结果的验收与纠正。
- **关键约束**：单次调用只处理一个学科，完成后停止等待人工验证；
  受限来源不得臆测内容，一律判 B 类并转人工。

检索过程的每一步更正均留有记录（`检索工作日志.txt` 中可检索「更正」「口径」等关键词）。

## 七、校验方法

`MANIFEST-SHA256.txt` 记录本版本全部文件的 SHA-256 哈希，
供**脱离 Git** 的副本（云盘同步、打包下载）核验完整性。

Windows PowerShell：

```powershell
Get-ChildItem -Recurse -File -Force |
  Where-Object { $_.Name -ne 'MANIFEST-SHA256.txt' } |
  ForEach-Object {
    $h = (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower()
    $rel = $_.FullName.Replace((Get-Location).Path + '\', '')
    "$h  $rel"
  } | Sort-Object
```

与清单逐行比对即可。macOS / Linux 可用 `sha256sum -c`。

**注意**：本仓库全部文本文件保持 Windows 换行（CRLF）原样，未作转换，
以确保校验结果与原始工作副本一致。详见 `.gitattributes`。
